# Pair-Extraordinaire

A small collaboration demo repository by Muhanned Amged and Omar Amged.

## Purpose

Practice a clean, co-authored GitHub workflow: feature branch, pull request,
review, and merge — while keeping commit attribution correct for both authors.

## Workflow

1. Create a feature branch from `main`.
2. Make a focused change and commit with a `Co-authored-by` trailer.
3. Open a pull request against `main`.
4. Review the diff and merge without squashing, so co-authorship is preserved.
